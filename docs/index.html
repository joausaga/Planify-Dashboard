Planify Dashboard

Una aplicación Android de código abierto que reúne en una pantalla los eventos y rutinas de Google Calendar, las tareas de Google Tasks y el pronóstico de Open-Meteo.

Qué hace

Planify Dashboard muestra información para consulta en una tablet o pantalla familiar. La aplicación accede a Google Calendar y Google Tasks con permisos de solo lectura. No crea, modifica ni elimina eventos, calendarios, tareas o listas.

Los datos de Google se solicitan directamente a las API oficiales y se procesan en el dispositivo. La aplicación también puede consultar Open-Meteo para mostrar el tiempo de una ubicación elegida por la persona usuaria.

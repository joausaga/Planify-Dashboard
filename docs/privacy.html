Planify Dashboard

Política de privacidad

Última actualización: 28 de octubre de 2026

Esta política describe cómo Planify Dashboard, una aplicación Android de código abierto para uso personal y familiar, accede y trata información al conectar Google Calendar y Google Tasks.

Datos de Google que se solicitan

Con autorización de la persona usuaria, la aplicación solicita acceso de solo lectura a Google Calendar y Google Tasks. Lee los calendarios y sus eventos dentro del intervalo necesario para mostrar el calendario, los próximos eventos y las rutinas; también lee las listas de tareas y las tareas pendientes. No solicita acceso para crear, editar o borrar esos datos.

Cómo se usan y comparten

Los datos se usan únicamente para mostrar las funciones del dashboard y para recordar en el dispositivo qué calendarios y listas se muestran. Las solicitudes se envían directamente desde la aplicación a las API de Google. Planify Dashboard no opera un servidor propio que reciba esos datos, no los vende ni los comparte con anunciantes y no los usa para publicidad o para entrenar modelos de inteligencia artificial.

Google procesa las solicitudes conforme a sus propios términos y políticas. La aplicación consulta Open-Meteo para obtener información meteorológica; al buscar o solicitar el pronóstico, se transmite a ese servicio el nombre de la ubicación buscada o las coordenadas de la ubicación seleccionada. El sitio informativo se aloja en GitHub Pages, que puede procesar datos técnicos de acceso conforme a sus políticas.

Almacenamiento y conservación

Los eventos, rutinas, tareas y pronósticos pueden quedar en una caché local privada de la aplicación para mostrar el dashboard con rapidez y permitir su visualización temporal sin conexión. La caché se actualiza al sincronizar y se elimina al cerrar sesión para los datos de Google; Android también la elimina al desinstalar la aplicación o borrar sus datos. La aplicación no guarda el access token de Google en sus preferencias locales: Play Services administra la autorización y la aplicación mantiene el token temporalmente en memoria para realizar solicitudes.

Los ajustes de visualización, ubicación y horario se guardan localmente en el dispositivo. Las selecciones de calendarios y listas se asocian localmente al identificador del calendario principal de la cuenta, no al correo electrónico.

Control de la persona usuaria

La persona usuaria puede retirar el acceso desde los ajustes de su cuenta de Google o cerrar sesión en Planify Dashboard. Al cerrar sesión, la aplicación intenta revocar el token actual y elimina su caché de datos de Google. La revocación también puede gestionarse en la página de permisos de la cuenta de Google.

Seguridad y menores

La información de dashboard se conserva en el almacenamiento privado de la aplicación en el dispositivo. La persona responsable del dispositivo debe proteger su acceso físico. Planify Dashboard no está dirigida a menores para que creen cuentas o proporcionen datos personales por separado.

Cambios y contacto

Esta política puede actualizarse si cambian las funciones o el tratamiento de datos. Las versiones vigentes se publicarán en esta página. Para consultas sobre privacidad, escribe a jorgesaldivar@gmail.com.
